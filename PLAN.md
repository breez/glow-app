# Glow App — Native Capacitor Wrapper

## Context

Wrap glow-web (React+Vite+WASM Bitcoin wallet) with Capacitor for native iOS/Android distribution. New repo `breez/glow-app` with glow-web as a git submodule.

**Priorities:**
1. Native shell with WASM working in WebView
2. Native passkey PRF flow (WebAuthn unavailable in WebViews — need native bridge)
3. Seed stored in iOS Keychain / Android Keystore (biometric-protected)
4. Later: push notifications for Lightning address payments

**Key resource**: Spark SDK PR #781 (`pr/passkey-core`) has native iOS/Android PRF provider code we'll reuse.

## Phase 1: Repo Setup & Capacitor Scaffold

### 1.1 Create repo
- `gh repo create breez/glow-app --private`
- Add glow-web as submodule: `git submodule add https://github.com/breez/glow-web.git glow-web`
- Create README.md, PLAN.md, CLAUDE.md

### 1.2 Initialize Capacitor project
- `npm init -y`
- Install: `@capacitor/core`, `@capacitor/cli`, `@capacitor/ios`, `@capacitor/android`
- `npx cap init --name Glow --id technology.breez.glow --webDir glow-web/dist`

### 1.3 Configure `capacitor.config.ts`
- `webDir: 'glow-web/dist'` (submodule build output)
- COOP/COEP headers for SharedArrayBuffer:
  ```ts
  server: {
    androidScheme: 'https',
    headers: {
      'Cross-Origin-Embedder-Policy': 'require-corp',
      'Cross-Origin-Opener-Policy': 'same-origin',
    },
  }
  ```

### 1.4 Add native platforms
- `npx cap add ios && npx cap add android`
- Commit `ios/` and `android/` directories

### 1.5 Build & verify
- Build glow-web: `cd glow-web && npm install && npm run build`
- Sync: `npx cap sync`
- Open iOS: `npx cap open ios` -- verify app loads, WASM inits, no crashes
- Passkey expected to fail gracefully at this point (`isPrfAvailable()` -> false)

### Files created
- `package.json`, `capacitor.config.ts`, `tsconfig.json`
- `README.md`, `PLAN.md`, `CLAUDE.md`, `.gitignore`, `.gitmodules`
- `ios/`, `android/` (generated)

## Phase 2: Passkey PRF Capacitor Plugin

Native bridge for passkey PRF. No existing Capacitor plugin supports the PRF extension. Native code comes from SDK PR #781.

### 2.1 Plugin structure
```
plugins/capacitor-passkey-prf/
  package.json                  # capacitor plugin manifest
  src/
    definitions.ts              # TS interface: isPrfAvailable, createPasskey, derivePrfSeed
    index.ts                    # registerPlugin
    web.ts                      # Web fallback using navigator.credentials (WebAuthn)
  ios/Sources/PasskeyPrfPlugin/
    PasskeyPrfPlugin.swift      # Capacitor bridge (@objc methods)
    PlatformPasskeyPrfProvider.swift   # From SDK PR #781 (ASAuthorization)
    PasskeyPRFHelper.h/.m       # ObjC helper for PRF types
  android/src/main/kotlin/.../
    PasskeyPrfPlugin.kt         # Capacitor bridge (@PluginMethod)
    CredentialManagerPrfCore.kt  # From SDK PR #781 (CredentialManager)
  android/build.gradle          # androidx.credentials deps
```

### 2.2 Plugin TypeScript interface
```ts
isPrfAvailable(): Promise<{ available: boolean }>
createPasskey(options: { rpId, rpName, userName?, userDisplayName? }): Promise<void>
derivePrfSeed(options: { rpId, salt }): Promise<{ seed: string }> // base64-encoded 32 bytes
```

### 2.3 Integration with glow-web

Runtime detection in glow-web (PR to breez/glow-web):
- `src/services/capacitorPasskeyPrfProvider.ts` -- implements `PasskeyPrfProvider` via Capacitor plugin bridge
- Factory in `passkeyPrfProvider.ts`: `Capacitor.isNativePlatform() ? CapacitorProvider : BrowserProvider`
- `@capacitor/core` as optional peer dependency (no-op on web)

### 2.4 Platform config required
- **iOS**: Associated Domains entitlement `webcredentials:keys.breez.technology`, deployment target iOS 18+
- **Android**: `assetlinks.json` registered on `keys.breez.technology`, minSdk 28, credentials deps
- **Both**: Contact Breez team to register `technology.breez.glow` on `keys.breez.technology`

### Verify
- iOS simulator: passkey creation triggers ASAuthorization sheet, PRF returns 32-byte seed, wallet connects
- Android device (emulators often lack credential providers): CredentialManager dialog, same flow
- Web browser: regression -- existing passkey flow unchanged

## Phase 3: Keychain Seed Storage

Cache derived seed in native keychain with biometric protection. Repeat launches: 1 biometric prompt instead of full passkey ceremony.

### 3.1 Install secure storage
- `@capacitor-community/secure-storage` (wraps iOS Keychain / Android Keystore)

### 3.2 Create `src/services/secureStorage.ts`
- `storeSeed(seed, label)` -- store after passkey derivation
- `retrieveSeed()` -- try on launch, returns null if not found or biometric fails
- `clearSeed()` -- on logout
- All no-op on web (`Capacitor.isNativePlatform()` guard)

### 3.3 Integrate into glow-web's `useBreezSdk.ts`
Three touch points (also via PR to glow-web):
- **Startup**: try `retrieveSeed()` before checking mnemonic/passkey mode
- **Post-connect**: `storeSeed()` after successful SDK connect
- **Logout**: `clearSeed()` alongside existing cleanup

### Flow
```
App launch (native) -> retrieveSeed() [biometric prompt]
  -> found -> connect directly (skip passkey ceremony)
  -> not found -> fall through to existing passkey/mnemonic flow
```

### Verify
- First launch: passkey flow, seed stored in keychain
- Second launch: biometric only, wallet connects instantly
- Logout: seed cleared
- Web: unchanged
